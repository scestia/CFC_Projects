# Cybersecurity Projects Portfolio 🚀
## Completed During My Training at Centre for Cybersecurity Institute (CFCI)

Welcome! This repository highlights a collection of hands-on cybersecurity projects I developed while undergoing the Cybersecurity Vocational Training Programme at CFCI. These projects reflect my growing capabilities in areas such as threat detection, penetration testing, network analysis, and cybersecurity operations.

---

## 📌 Project Highlights

### 🔍 1. Network Scanning & Enumeration
- **Tools used**: Nmap, Netcat, Wireshark
- **Description**: Automated scripts to identify live hosts, open ports, and services on a local subnet. Included logging and report generation for each scan.
- **Skills demonstrated**: Bash scripting, subnetting, protocol analysis

### 🛡️ 2. Penetration Testing Toolkit
- **Tools used**: Hydra, Medusa, Searchsploit
- **Description**: A toolkit combining brute-force password auditing, exploit lookups, and vulnerability mapping.
- **Skills demonstrated**: Offensive security, password auditing, exploit research


### 🌐 5. DNS & DHCP Traffic Capture and Analysis
- **Tools used**: Wireshark
- **Description**: Captured and interpreted DNS and DHCP traffic to understand protocol behavior and common misconfigurations.
- **Skills demonstrated**: Network forensics, protocol analysis
